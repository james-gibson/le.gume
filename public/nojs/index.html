No script

This page was delivered whole. There is no <script> element in this file, no bundle behind it, and nothing here will run after the last byte arrives. What you see is what the server sent.

The rest of this site is a React application. With JavaScript disabled it renders an empty box and a title — you can try it, the box is honest about it. This page exists to show that the words never needed the application.

What still works

  • Reading, in the order the document was written.
  • Links, including the browser's back button.
  • Find in page, bookmarks, screen readers, print, reader mode.
  • Fetching it with curl, if that is your idea of reading.

What does not

  • Client-side routing: every link is a real request.
  • The motion budget, the seed scale widget, the QR handoff.
  • Anything that needed a state update to become true.

The trade, in a table

Property Single-page app This page
Time to first word After the bundle parses On arrival
Works with JS off No By construction
Route change Instant A request
Failure mode A blank page that looks fine in testing A 404, which is at least true
