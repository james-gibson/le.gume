No stylesheet

This page has no CSS. Not a reset, not a theme with the colours removed: no stylesheet is requested, there is no <style> element, and nothing here carries a style attribute.

What you are looking at is the browser's default rendering of a document. The other pages on this site use a design system; this one uses the user agent stylesheet, which has shipped with every browser since the web stopped being a physics experiment.

What survived

  • Headings, at the sizes the browser chose.
  • Paragraphs, with margins the browser chose.
  • Links, in the blue and purple everyone under forty has never seen.
  • Lists, both kinds, with markers.
  • Code, in whatever monospace font the operating system recommends.
  • Tables, without borders, because borders were never the table's job.

What did not

  • Contrast, hierarchy by weight, and anything resembling a grid.
  • Dark mode. This page is whatever your browser thinks a document is.
  • The site's navigation, the seed scale, the QR handoff, the motion budget.
